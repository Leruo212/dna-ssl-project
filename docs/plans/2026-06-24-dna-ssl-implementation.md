# DNA序列分类自监督表示学习实施计划

## 概述
本计划详细描述DNA序列分类自监督表示学习项目的实施步骤。每个任务约2-5分钟，遵循TDD原则：写测试 → 看失败 → 实现 → 看通过 → 提交。

## 任务清单

### 任务1：项目初始化和依赖安装
**目标**：创建项目结构，安装必要依赖

**步骤**：
1. 创建项目目录结构
2. 创建`requirements.txt`文件
3. 安装依赖包
4. 创建基础配置文件

**测试**：
- 验证目录结构存在
- 验证依赖包可导入

**预计时间**：3分钟

### 任务2：数据下载和预处理
**目标**：下载NCBI RefSeq数据，进行预处理

**步骤**：
1. 下载人类、小鼠、果蝇、线虫的DNA序列
2. 清洗数据，去除异常序列
3. 统一序列长度（500-1000bp）
4. 保存为统一格式

**测试**：
- 验证数据文件存在
- 验证序列长度符合要求
- 验证物种标签正确

**预计时间**：5分钟

### 任务3：k-mer编码实现
**目标**：实现DNA序列的k-mer编码

**步骤**：
1. 构建3-mer词汇表（64种可能）
2. 实现DNA序列到k-mer序列的转换
3. 实现特殊token处理（CLS、SEP、PAD、MASK）
4. 实现序列填充/截断功能

**测试**：
- 验证词汇表大小正确
- 验证编码后序列长度一致
- 验证特殊token正确添加

**预计时间**：4分钟

### 任务4：数据集类实现
**目标**：实现PyTorch数据集类

**步骤**：
1. 创建`DNADataset`类
2. 实现`__len__`和`__getitem__`方法
3. 实现数据加载和预处理
4. 实现掩码生成逻辑

**测试**：
- 验证数据集大小正确
- 验证数据加载无错误
- 验证掩码生成正确

**预计时间**：3分钟

### 任务5：CNN编码器实现
**目标**：实现CNN编码器模型

**步骤**：
1. 创建`CNNEncoder`类
2. 实现嵌入层
3. 实现卷积层序列
4. 实现全局平均池化
5. 实现全连接层

**测试**：

## 执行模式选择

### 模式1：Subagent-driven（当前会话）
- 使用subagent执行每个任务
- 每个任务完成后进行代码审查
- 自动化程度高，适合快速完成

### 模式2：Manual execution（用户自己执行）
- 用户手动执行每个任务
- 每个任务完成后用户验证
- 适合学习过程，可深入理解每个步骤
