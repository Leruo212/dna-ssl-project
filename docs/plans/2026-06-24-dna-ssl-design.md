# DNA序列分类的自监督表示学习设计方案

## 1. 问题背景与应用场景

### 1.1 问题背景
DNA序列分类是生物信息学中的基础任务，广泛应用于物种鉴定、基因功能预测、进化分析等领域。然而，传统的监督学习方法面临以下挑战：

- **标签稀缺问题**：实验验证的基因功能注释需要昂贵的实验成本
- **标注成本高**：专业生物学家手动标注序列耗时耗力
- **未标注数据丰富**：NCBI等数据库中存在海量未标注的DNA序列

### 1.2 应用场景
本项目针对DNA序列分类任务，利用自监督表示学习方法从大量未标注DNA序列中学习有效表示，然后用于下游分类任务。

**具体应用场景**：
- 多物种DNA序列分类（人类、小鼠、果蝇、线虫等）
- 基于学习到的DNA序列表示进行物种鉴定
- 特征可视化分析DNA序列的进化关系

## 2. 自监督任务设计

### 2.1 掩码重构学习
采用掩码重构学习（Masked Reconstruction Learning）作为自监督任务，具体设计如下：

**掩码策略**：
- 随机掩码DNA序列中15%的碱基
- 掩码token替换为特殊的`[MASK]`符号
- 保持序列长度不变

**重构目标**：
- 预测被掩码位置的原始碱基（A、T、C、G）
- 使用交叉熵损失函数
- 只计算被掩码位置的损失

### 2.2 数据预处理
**k-mer编码**：
- 将DNA序列转换为k-mer表示（k=3）
- 每个k-mer作为一个token
- 构建词汇表：所有可能的3-mer组合（4^3=64种）

**序列编码**：
- 将DNA序列转换为k-mer序列
- 添加特殊token：`[CLS]`、`[SEP]`、`[PAD]`、`[MASK]`
- 填充/截断到固定长度（如512）

## 3. 表征学习方法实现

### 3.1 模型架构
**CNN编码器**：
```
输入层 → 嵌入层 → 卷积层1 → 卷积层2 → 卷积层3 → 全局平均池化 → 全连接层
```

**详细架构**：
1. **嵌入层**：将k-mer token转换为稠密向量（维度128）
2. **卷积层**：
   - 卷积层1：128个滤波器，核大小3，ReLU激活
   - 卷积层2：256个滤波器，核大小3，ReLU激活  
   - 卷积层3：512个滤波器，核大小3，ReLU激活
3. **池化层**：全局平均池化
4. **全连接层**：512 → 256（表示维度）

**重构头**：
- 全连接层：256 → 64（词汇表大小）
- 用于预测被掩码的k-mer

### 3.2 训练策略
**预训练阶段**：
- 优化器：Adam，学习率1e-4
- 批次大小：32
- 训练轮次：50
- 掩码比例：15%

**下游任务阶段**：
- 冻结编码器参数
- 添加分类头：256 → 4（物种数量）
- 微调分类头，学习率1e-3

## 4. 特征可视化或下游任务验证

### 4.1 特征可视化
**t-SNE降维**：
- 提取编码器输出的256维表示
- 使用t-SNE降维到2维
- 按物种着色，可视化聚类效果

**PCA分析**：
- 主成分分析，展示前两个主成分
- 分析方差解释比例

### 4.2 下游任务验证
**分类任务**：
- 在预训练表示上添加分类头
- 使用标注数据进行微调
- 评估指标：准确率、精确率、召回率、F1分数

**数据集划分**：
- 训练集：70%
- 验证集：15%
- 测试集：15%

- 有效利用未标注数据
