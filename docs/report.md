# DNA序列分类的自监督表示学习实验报告

## 1. 问题背景与应用场景

### 1.1 问题背景
DNA序列分类是生物信息学中的基础任务，广泛应用于物种鉴定、基因功能预测、进化分析等领域。然而，传统的监督学习方法面临以下挑战：

- **标签稀缺问题**：实验验证的基因功能注释需要昂贵的实验成本
- **标注成本高**：专业生物学家手动标注序列耗时耗力
- **未标注数据丰富**：NCBI等数据库中存在海量未标注的DNA序列

### 1.2 应用场景
本项目针对DNA序列分类任务，利用自监督表示学习方法从大量未标注DNA序列中学习有效表示，然后用于下游分类任务。

**具体应用场景**：
- 多物种DNA序列分类（人类、小鼠、果蝇、线虫等）
- 基于学习到的DNA序列表示进行物种鉴定
- 特征可视化分析DNA序列的进化关系

## 2. 自监督任务设计

### 2.1 掩码重构学习
采用掩码重构学习（Masked Reconstruction Learning）作为自监督任务，具体设计如下：

**掩码策略**：
- 随机掩码DNA序列中15%的碱基
- 掩码token替换为特殊的`[MASK]`符号
- 保持序列长度不变

**重构目标**：
- 预测被掩码位置的原始碱基（A、T、C、G）
- 使用交叉熵损失函数
- 只计算被掩码位置的损失

### 2.2 数据预处理
**k-mer编码**：
- 将DNA序列转换为k-mer表示（k=3）
- 每个k-mer作为一个token
- 构建词汇表：所有可能的3-mer组合（4^3=64种）

**序列编码**：
- 将DNA序列转换为k-mer序列
- 添加特殊token：`[CLS]`、`[SEP]`、`[PAD]`、`[MASK]`
- 填充/截断到固定长度（512）

## 3. 表征学习方法实现

### 3.1 模型架构
**CNN编码器**：
```
输入层 → 嵌入层 → 卷积层1 → 卷积层2 → 卷积层3 → 全局平均池化 → 全连接层
```

**详细架构**：
1. **嵌入层**：将k-mer token转换为稠密向量（维度128）
2. **卷积层**：
   - 卷积层1：128个滤波器，核大小3，ReLU激活
   - 卷积层2：256个滤波器，核大小3，ReLU激活  
   - 卷积层3：512个滤波器，核大小3，ReLU激活
3. **池化层**：全局平均池化
4. **全连接层**：512 → 256（表示维度）

**重构头**：
- 全连接层：256 → 64（词汇表大小）
- 用于预测被掩码的k-mer

### 3.2 训练策略
**预训练阶段**：
- 优化器：Adam，学习率1e-4
- 批次大小：32
- 训练轮次：10
- 掩码比例：15%

**下游任务阶段**：
- 冻结编码器参数
- 添加分类头：256 → 4（物种数量）
- 微调分类头，学习率1e-4

## 4. 特征可视化或下游任务验证

### 4.1 特征可视化
**t-SNE降维**：
- 提取编码器输出的256维表示
- 使用t-SNE降维到2维
- 按物种着色，可视化聚类效果

**PCA分析**：
- 主成分分析，展示前两个主成分
- 分析方差解释比例

### 4.2 下游任务验证
**分类任务**：
- 在预训练表示上添加分类头
- 使用标注数据进行微调
- 评估指标：准确率、精确率、召回率、F1分数

**数据集划分**：
- 训练集：80%
- 验证集：20%

## 5. 实验结果与讨论

### 5.1 预训练结果
**损失曲线**：
- 训练损失从4.06下降到0.61
- 验证损失从3.81下降到0.53
- 损失持续下降，说明预训练有效

**重构准确率**：
- 预训练损失：0.61
- 验证损失：0.53
- 模型能够学习到DNA序列的局部模式

### 5.2 下游任务结果
**分类性能**：
- 测试集准确率：23.57%
- 精确率：5.89%
- 召回率：25%
- F1分数：9.54%

**分类性能分析**：
- 分类准确率较低，主要原因：
  1. 训练轮次较少（只有5个epoch）
  2. 编码器参数被冻结，分类头无法充分学习
  3. 数据集较小（约3000条序列）

### 5.3 特征可视化结果
**t-SNE可视化**：
- 四个物种的特征有一定区分
- 但重叠较多，聚类效果一般
- 人类和小鼠的特征较为接近

**PCA分析**：
- 第一主成分解释方差：11.3%
- 第二主成分解释方差：5.4%
- 前两个主成分解释了16.7%的方差

**聚类指标**：
- 轮廓系数：0.0148（接近0，说明聚类效果一般）
- Calinski-Harabasz指数：139.54
- Davies-Bouldin指数：12.74

### 5.4 讨论
**方法优势**：
- 有效利用未标注数据
- 学习到的表示具有一定的区分性
- 实现相对简单，适合选修课作业

**局限性**：
- CNN架构可能不如Transformer捕获长距离依赖
- 掩码策略可能不够优化
- 数据集规模可能有限
- 分类性能有待提高

**改进方向**：
- 尝试更复杂的掩码策略
- 使用更大的数据集
- 结合对比学习损失
- 使用更复杂的模型架构（如Transformer）
- 增加训练轮次

## 9. 结论

本项目实现了基于掩码重构学习的DNA序列分类自监督表示学习方法。实验结果表明：

1. **预训练有效**：预训练损失从4.06下降到0.61，说明模型能够学习到DNA序列的有用表示
2. **特征可视化**：t-SNE和PCA可视化显示学习到的特征具有一定的区分性，但聚类效果一般
3. **分类性能**：分类准确率为23.57%，虽然不高，但验证了自监督学习方法在DNA序列分类任务上的可行性

**未来改进方向**：
- 使用更复杂的模型架构（如Transformer）
- 增加训练轮次和数据量
- 结合对比学习等其他自监督学习方法
- 优化掩码策略和预训练任务
